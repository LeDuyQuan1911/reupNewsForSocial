Trang này xác minh tên và ID Page bằng quyền đọc. Quyền đăng chỉ được xác nhận khi thử đăng một bài. Token không hiển thị trên website.

{{ 'Xem cách kiểm tra hoặc đổi Page' if page_ready else 'Cách kết nối Facebook Page' }}

Để vận hành tự động bằng System User, vào Business Settings → Người dùng hệ thống. Gán App CreatePost và đúng Page, cấp quyền tạo nội dung; tạo token với pages_show_list, pages_read_engagement, pages_manage_posts (thêm pages_manage_engagement nếu dùng bình luận video). Sau đó chạy .\scripts\configure-facebook-system-user.ps1 trong PowerShell và dán token ở lời nhắc ẩn. Dùng -Check để kiểm tra lại.

Đường kết nối Page token cũ:

  1. Nếu đã có Page token phù hợp, chuyển tới bước 4. Nếu chưa, dùng Meta App đang có hoặc tạo App mới để lấy token.
  2. Trong Graph API Explorer, chọn App, cấp quyền quản lý/đăng Page và tạo User access token.
  3. Gọi /me/accounts?fields=id,name,access_token,tasks, chọn đúng Page rồi lấy Page ID và Page access token. Giữ token trên máy của bạn.
  4. Mở PowerShell tại repo và chạy .\scripts\configure-facebook-page.ps1{{ ' -Check' if page_ready else '' }}. Script kiểm tra tên/ID Page trước khi lưu cấu hình.

Sau khi cấu hình, hãy xem bài đang chờ trước khi để lịch tự chạy.
