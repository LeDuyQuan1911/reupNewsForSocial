# Plugin: Documentation

Nhật ký từng nhiệm vụ trong `docs/worklog/` là bắt buộc dù plugin này tắt. Khi plugin này bật, mỗi chức năng hoàn thành còn cần tài liệu đủ để người mới chạy, sử dụng và tìm đúng phần code liên quan.

- Cập nhật `README.md` với lệnh chạy, cấu hình cần có và cách kiểm tra đã được xác minh.
- Cập nhật `MAP.md` khi entry point, module hoặc luồng dữ liệu thay đổi.
- Mô tả API, định dạng dữ liệu hoặc thao tác vận hành khi sản phẩm thực sự có các thành phần đó.
- Dùng ví dụ giả, không đưa secrets hay dữ liệu riêng tư vào tài liệu.

Không tạo tài liệu mô tả chức năng chưa tồn tại.
